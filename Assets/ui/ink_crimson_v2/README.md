# Ink Crimson UI v2

`hud_ornament.png` is the editable ornament used by the compact combat HUD. It is a transparent PNG so it can be opened and repainted directly in Aseprite. The runtime content (text, bars, buttons, cooldowns and organ slots) is generated in GDScript and remains separate from the ornament.

`shiba_silhouette.png` and its `.ase` source are used behind the organ slots. The palette follows the Ink Crimson ten-color contract in `Docs/INK_CRIMSON_VISUAL_SYSTEM.md`.
